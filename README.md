# ПЕРЕМЕНА+
## Маленький пуф. Большая перемена.

Интерактивный сайт школьного проекта: дополнительные места для короткого отдыха и общения в коридорах. Шесть разделов, а не набор изображений слайдов.

### Посмотреть
Откройте `index.html` в современном браузере. Сайт работает без сборки, сервера и интернета. Все изображения и исходные презентации находятся рядом в папках `assets` и `downloads`. Для интерактивных функций требуется JavaScript.

### Что внутри
Кинематографическое вступление на настоящей фотографии коридора: сначала без новых пуфов, затем два пуфа появляются по очереди. Интерактивные карточки сценариев перемены. Вращаемый 3D-эскиз с тремя оттенками и переключением на фото товара. WebGL дополняется программным 3D-рендерером для компьютеров без аппаратного ускорения; при отсутствии обоих остаётся фото. Слайдер «до / после» с одинаковым кадрированием. Калькулятор количества и бюджета. Автоматический показ шести разделов с паузой, стрелками и полноэкранной кнопкой. Отдельный режим уменьшенного движения. PDF и PowerPoint для скачивания.

### Визуализации и безопасность
На фото показан только фрагмент проекта: два из десяти пуфов. Масштаб и места условные; школьное согласование и замеры обязательны. Проходы, двери, радиаторы и шкафчики должны оставаться доступными. Изображение с учениками — художественная иллюстрация, не фотография учеников школы. 3D — оригинальный геометрический эскиз, не точный файл производителя. Никакие медицинские, учебные или сертификационные свойства товара не заявлены.

### Опубликовать на GitHub
Откройте эту папку в VS Code и передайте Codex задание из `DEPLOY_CODEX.md`.
Для первой публикации предусмотрены `publish-github.ps1` (Windows PowerShell) и `publish-github.sh` (Bash/WSL). Нужны установленные Git и GitHub CLI и ваша авторизация через браузер. Скрипт проверяет аккаунт Maksimas-win, создаёт новый публичный репозиторий peremena-plus, загружает main, включает Pages и проверяет результат. При существующем репозитории или локальной .git он останавливается, ничего не перезаписывая.

Сценарии публикации не запускались в среде создания сайта: подключённый здесь инструмент GitHub предоставлял только операции чтения. Активной публикации в этом комплекте не заявлено.

### Управление
«Показ» — автоматический рассказ по шести разделам; длинные разделы слегка прокручиваются, чтобы показать нижнюю часть. Стрелки клавиатуры — назад/вперёд, Esc — выход. Кнопка со значком искры уменьшает движение. Пуф вращается перетаскиванием; при фокусе на 3D-объекте работают стрелки и Home. Ползунки доступны с клавиатуры. При открытой вкладке вращается только видимый объект.

### Технические детали
Обычные HTML/CSS/JavaScript; зависимости и удалённые шрифты отсутствуют. Изображения оптимизированы в WebP. Рендеринг останавливается вне экрана и при скрытии вкладки. Сайт не содержит аналитики, форм, API-ключей, счётчиков голосов или отправки данных учеников.

`tests/QA_REPORT.md` описывает реально выполненные проверки и ограничения. Существующие PDF/PPTX включены без изменения их содержания.
