# Задание для Codex: опубликовать готовый проект

Сайт уже создан. Не переписывай дизайн и не начинай проект заново.

1. Прочитай AGENTS.md. Убедись, что открыт корень именно этого проекта: index.html, assets/, downloads/.
2. Проверь авторизацию GitHub. Нужен аккаунт Maksimas-win. Не запрашивай токены в чате: при необходимости используй штатную авторизацию GitHub CLI через браузер.
3. Проверь, существует ли Maksimas-win/peremena-plus. Для первой публикации создай отдельный публичный репозиторий. Если репозиторий уже есть — сначала прочитай содержимое, ветки и remote; не перезаписывай неизвестный проект.
4. Проверь локально JavaScript, пути к файлам и поведение сайта. Node нужен только для `node --check`, но не для работы сайта.
5. Размести файлы в корне ветки main. Для первой публикации можно выполнить publish-github.ps1 в PowerShell или `bash publish-github.sh` в WSL/macOS/Linux. Прочитай сценарий перед запуском. Он останавливается, если видит существующий репозиторий или .git.
6. Включи GitHub Pages: Deploy from a branch → main → /(root). Не настраивай Hostinger и пользовательские домены.
7. Дождись успешного Pages build. Проверь конечный публичный URL: HTTP 200, заголовок ПЕРЕМЕНА+, canvas pouf-canvas, CSS/JS/изображения и PDF/PPTX без 404.
8. Проверь ширины 390, 768 и 1440 px. Проверь появление пуфов, вращение 3D, оттенки, фото/3D, слайдер до/после, количество от 1 до 10, сумму 750 € и резерв 50 €, режим показа, Esc, reduced motion.
9. После подтверждённой публикации установи абсолютные canonical, og:url и og:image на реальный URL, если это нужно для предпросмотра в соцсетях. Не добавляй выдуманный опубликованный адрес.
10. Верни реальный адрес сайта, репозитория, хеш коммита и результат проверок. Если доступ или сборка не удались — точно укажи, на каком шаге остановился.

Важно: не трогай другие репозитории Maksimas-win, сайты прихода, pasha.lt, Hostinger и DNS. Не используй force push.
