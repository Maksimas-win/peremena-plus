# PEREMENA+ — instructions for Codex and other coding agents

## Scope
This is a standalone static school presentation. Use only this project/repository.
Do not touch any parish website, pasha.lt, Hostinger, DNS, other repositories or account-wide settings.
Do not force-push, delete repositories or bypass protections.

## Architecture
- index.html: six story chapters, semantic controls, source-price modal.
- assets/style.css: responsive design, cinematic opening, motion preferences.
- assets/app.js: reveal, real before/after, calculator, six-chapter show, sharing.
- assets/model3d.js: original procedural geometry, native WebGL plus software 3D renderer.
- assets/*.webp: supplied school photos, supplied product photo, illustrative people scene.
- downloads/: previously prepared PDF and PowerPoint.
No framework, Node build, remote CDN, font files, API keys, backend or tracker is required.

## Do not regress
1. Empty original corridor first, then two poufs appear; opening is replayable and skippable.
2. 3D must rotate actual geometry, not just skew a PNG; keep photo fallback.
3. Pause rendering off screen or in hidden tabs; respect reduced motion.
4. Before/after must preserve exactly the same original photo and perspective.
5. 10 x 75 EUR = 750 EUR. 800 EUR budget leaves 50 EUR reserve. The price is from the supplied screenshot, not a current verified quote.
6. State that 3D and placement are illustrative, and that dimensions/safety/cleaning/supplier terms must be checked.
7. Do not invent student numbers, health/academic benefits, manufacturer certifications, reviews, votes, school name or class.
8. Keep generated people image labelled as an illustration, not a photograph of the school's students.
9. Do not collect student data. A celebratory button is not a vote.
10. All relative assets must work under a GitHub Pages repository subpath.
11. No user font files. Use system typography.
